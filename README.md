# Healthcare Analytics Dashboard (Power BI)

Advanced healthcare analytics dashboard developed using Power BI to monitor patient admissions, department performance, billing vs payments, and outstanding balances through interactive visualizations.

## Project Overview
This project presents an interactive healthcare analytics dashboard built using Power BI to analyze patient flow, billing performance, payments, and outstanding amounts for better operational and financial decision-making.

## Key Features
- KPI cards for total patients, admissions, billing, and payments
- City-wise and gender-wise patient distribution
- Department-wise and procedure-wise admission analysis
- Billing vs payment comparison
- Outstanding amount tracking
- Interactive slicers and filters

## Tools & Technologies
- Power BI
- Excel

## Project Objective
To provide healthcare management with actionable insights into patient flow, operational efficiency, and financial performance.
